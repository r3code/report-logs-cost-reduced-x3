# Кейс 1: Стена аннотаций K8s

- Лимит **63 символа** на ключ аннотации K8s
- Имена меток сервисов не влезали → выборочный сбор ломался
- Решение: собираем **всё**, исключаем по namespace label
- Метка: `tags.vitech.team/service_name`

::right::

<div class="pl-4">

```toml {all|3|4-7|all}
# Vector: исключаем шумные namespace
[transforms.filter]
type = "filter"
condition = '''
  !contains(
    tags."vitech.team/service_name",
    "noise-"
  )
'''
```

</div>
