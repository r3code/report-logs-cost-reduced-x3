# Побочный эффект: генерация метрик

<ProgressiveList :items="['Раньше: копипаст VRL-кода для метрик каждого сервиса', 'Теперь: единый metrics-catalog.yml → Ansible/Jinja', 'Время на добавление метрики: 5 часов → 20 минут', 'Единый источник истины, ноль рассинхрона']" />

::right::

<div class="pl-4">

```yaml
# metrics-catalog.yml — генерация
# VRL-правил и SQL-схем через Jinja
services:
  - name: billing
    metrics:
      - http_request_duration_seconds
      - payment_errors_total
    ttl_hours: 720
```

</div>
